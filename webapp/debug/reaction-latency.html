The mechanism, at median pace

t = 0 is the user finishing a sentence while the robot's idle heartbeat turn is mid-think. Before: the loop is sequential, so the reply waits out the heartbeat and its speech is then suppressed as stale — pure dead time. After: the heartbeat turn is cancelled (transactionally, nothing consumed) and rerun with the user's message included.

The cancelled turn costs nothing: events are only consumed when a turn commits, so the rerun sees everything the heartbeat saw, plus the user's message. Turns that began on a user event are never preempted — a correction queues instead, so rapid back-to-back speech can't starve the loop.

Shrinking the think

gemini-3.6-flash won't run with thinking fully off (thinkingBudget: 0 and thinkingLevel: "none" are rejected with HTTP 400); the accepted ladder is minimal / low / medium / high. Method & caveats

Harness: the real BrainAgent with production transport (Innate proxy → Gemini), production system prompt and tool declarations (2 skills + go-to-point + wait), and a synthetic 640×480 camera frame. Camera, runner, and chat collaborators are stubs; timing is stamped at the transport boundary and the /brain/trace sink. Baseline arm restores the old sequential flow on the same build; arms alternate to neutralize network drift.

Reaction = injection → commit of the turn carrying the user's message (through decision + tool outcomes, speech stubbed). The 1.2 s injection offset is an average case: heartbeat thinks ran 2.1–2.8 s, so baseline waits of 0.9–1.6 s. Speech landing earlier in a longer turn pays proportionally more; preemption caps dispatch at ~1 ms regardless.

Thinking level: probes are single-turn, 3 reps per scenario per level; grounding accuracy judged against known scene geometry. An earlier model's low hurt multi-turn discipline (skill re-runs, chatter) — that regression class isn't covered by these probes, so llm_thinking (gemini_thinking_level when this ran) in core/config.py documents the revert path back to "". All 24 preemption-bench injections landed mid-think; 53 unit tests pass.

Remaining levers: streaming the response into TTS sentence-by-sentence, and killing the speaker on user barge-in. Changes: _preemptible_turn in brain_client/brain/agent.py; the thinking-level default in brain_client/core/config.py.
