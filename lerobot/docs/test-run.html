MARS LeRobot Test Run

Six stages, each with the command to run, where to run it, and what a pass looks like. Tick boxes as you go; they stay ticked in this browser.

0 / 0 done

0Before you start

on the robot

innate update --dev apply feat/lerobot-integration     # or: git pull && innate build

Pass: innate view, manipulation server window shows LeRobot bridge listening on :5555 (actions) and :5556 (observations). The same line appears on the webapp Logging page.

on the laptop, same Wi-Fi as the robot

cd innate-os/lerobot && uv sync
export MARS_HOST=mars-the-2nd.local     # the hostname you use for the web app
uv run lerobot-record --help

Pass: help text prints. All later commands run from this folder in this shell; MARS_HOST is where they find the robot.

One task, one object, one placement area. Set the head angle from the app and leave it alone for the whole run; recording and inference must see the same view. Optional: uv run hf auth login if you want to push a private dataset later.

1Teleop passthrough

laptop

uv run lerobot-teleoperate --robot.type=mars \
    --robot.external_commands=true --teleop.type=mars_passthrough --display_data=true

Drive the arm and base from the phone app for a minute. Ctrl+C to stop.

Pass: the terminal reports Teleop loop time: ~34ms (29 Hz); a Rerun window shows both cameras live and joint plots that follow your input; the webapp log shows LeRobot client connected, then LeRobot client idle after Ctrl+C. Note: how long connect took, any warnings.

2Collect a dataset

laptop

uv run lerobot-record \
    --robot.type=mars --robot.external_commands=true --teleop.type=mars_passthrough \
    --dataset.repo_id=YOUR_HF_NAME/mars-pick-cube --dataset.no_stamp=true \
    --dataset.single_task="Pick up the red cube" --dataset.fps=30 \
    --dataset.num_episodes=30 --dataset.episode_time_s=30 --dataset.reset_time_s=15 \
    --dataset.push_to_hub=false
KeyDoes
→ right arrowend the episode now (task done)
← left arrowdiscard and re-record this episode
Escstop the session; resume later with the same command plus --resume=true

Pass: the session ends with 30 episodes saved under ~/.cache/huggingface/lerobot/YOUR_HF_NAME/mars-pick-cube. Note: whether the loop reported slow ticks.

laptop

uv run lerobot-dataset-viz --repo-id YOUR_HF_NAME/mars-pick-cube --episode-index 0

Pass: both camera streams play in Rerun, in colour (not blue-tinted), with joint plots that match what you did. Gripper is joint6.pos.

3Replay

First time lerobot moves the robot
Clear the arm's workspace and give the base room: recorded base motion replays too. Keep the app's stop button at hand. Ctrl+C stops the arm commands and the base halts by itself half a second later.

laptop

uv run lerobot-replay --robot.type=mars \
    --dataset.repo_id=YOUR_HF_NAME/mars-pick-cube --dataset.episode=0

Pass: the arm and base repeat the recorded motion at the recorded speed. Note: any jerkiness or lag between command and motion compared with the app.

4Train ACT

laptop (Apple Silicon GPU), or a CUDA box with --policy.device=cuda

uv run lerobot-train \
    --dataset.repo_id=YOUR_HF_NAME/mars-pick-cube \
    --policy.type=act --policy.device=mps \
    --output_dir=outputs/train/act_mars --job_name=act_mars \
    --steps=20000 --batch_size=8 --save_freq=5000 \
    --wandb.enable=false

Pass: loss trends down over the run; checkpoints appear under outputs/train/act_mars/checkpoints/. Twenty thousand steps is a first pass; the default is 100k. Training elsewhere: push the dataset first with --dataset.push_to_hub=true --dataset.private=true on the record command.

5Inference on the robot

laptop, same scene and head angle as in stage 2

uv run lerobot-rollout --strategy.type=base \
    --policy.path=outputs/train/act_mars/checkpoints/last/pretrained_model \
    --policy.device=mps \
    --robot.type=mars \
    --task="Pick up the red cube" --duration=60

Pass: the robot moves purposefully toward the object; with 30 episodes expect some successes, not reliability. Note: success count out of attempts, and whether it looked slower or noisier than the in-house ACT. The bridge refuses lerobot's commands while an Innate skill runs.
